# Heart-Disease-Prediction-XAI
An Explainable Machine Learning framework for early heart disease prediction using clinical and lifestyle data. This project compares eight ML algorithms and integrates LIME-based Explainable AI (XAI) to provide transparent, interpretable, and reliable predictions for clinical decision support.

# ❤️ Explainable Heart Disease Prediction using Machine Learning

## Overview

This project presents an Explainable Machine Learning framework for early heart disease prediction using clinical and lifestyle data.

The framework compares multiple Machine Learning algorithms and applies Explainable Artificial Intelligence (XAI) using Local Interpretable Model-Agnostic Explanations (LIME) to explain individual predictions.

---

## Algorithms Used

- Logistic Regression
- Naïve Bayes
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- Decision Tree
- Random Forest
- Artificial Neural Network (ANN)
- XGBoost

---

## Explainable AI

LIME is used to explain:

- Prediction probability
- Feature importance
- Local explanations
- Individual patient prediction

---

## Dataset

Cleveland Heart Disease Dataset

Additional lifestyle features:

- Smoking
- Alcohol

## Results

| Model | Accuracy |
|--------|----------|
| Logistic Regression | 88.66% |
| Naïve Bayes | 87.91% |
| SVM | 89.42% |
| KNN | 94.71% |
| Decision Tree | 95.72% |
| Random Forest | 99.24% |
| ANN | 89.42% |
| XGBoost | 98.49% |

Random Forest achieved the highest prediction accuracy.
